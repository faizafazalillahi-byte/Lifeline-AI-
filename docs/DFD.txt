LEVEL 2 — SOS / AI SUB-PROCESS (DETAIL OF PROCESS 3.0)
--------------------------------------------------------------------
 [User taps SOS]
        |
        v
 3.1 Get GPS lat/long (Geolocation API)
        |
        v
 3.2 Collect features: time_of_day, emergency_type, description length,
     user's historical alert count, movement pattern, heart-rate flag(optional)
        |
        v
 3.3 severity_model.predict(features) --> Low / Medium / High / Critical
        |
        v
 3.4 fake_alert_detector.check(features, history) --> fake_score (0-1)
        |
        v
 3.5 IF fake_score > threshold --> flag is_fake_suspected = TRUE
     (still logged, but admin sees a warning badge)
        |
        v
 3.6 INSERT INTO emergencies (... severity_level, severity_score,
     is_fake_suspected, fake_score, status='pending')
        |
        v
 3.7 Query nearest hospital & police station (haversine / Places API)
        |
        v
 3.8 Create notification record + push to admin dashboard (poll/refresh)
        |
        v
 3.9 Return response to client: {severity, nearest_hospital, nearest_police,
     emergency_id} --> rendered on SOS screen + live map
